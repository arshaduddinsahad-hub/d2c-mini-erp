# n8n Workflows

This folder contains version-controlled exports of the project's n8n workflows.

## Phase 3 Core Workflows

- Phase3 - Reserve Stock
- Phase3 - Commit Stock
- Phase3 - Release Stock
- Phase3 - Restock
- Phase3 - Lifecycle Orchestrator

## Rules

- n8n is the automation/orchestration engine.
- Supabase is the source of truth.
- Workflow exports must not contain secrets or credentials.
- Production workflow changes should be reviewed before deployment.
- Do not overwrite a verified milestone without preserving the previous version.
